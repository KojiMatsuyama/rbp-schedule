

### 1. 病害虫次元の定義（DISEASE_DIM）

まず、全セットに登場する病害虫を列挙し、  
ベクトルの次元順を固定します。

```
DISEASE_DIM = [
  炭疽病,           // d1
  灰色かび病,       // d2
  うどんこ病,       // d3
  ナミハダニ,       // d4
  ハスモンヨトウ,   // d5
  オオタバコガ,     // d6
  ミカンキイロアザミウマ, // d7
  ワタアブラムシ,   // d8
  アブラムシ,       // d9
  コナジラミ        // d10
]
```

各評価BOXの `vector` は **長さ10の 0/1 ベクトル**で、  
上記順序に対応します。
