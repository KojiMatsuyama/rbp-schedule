# ENTRY_VECTOR（病害虫予報ベクトル）生成方法

---

## 1. 基本構造

### ベクトル次元
```
n = 防除カタログに出現する病害虫の総種類数 = 10
```

### 病害虫インデックス（次元マッピング）
```
次元 0 : 炭疽病
次元 1 : 灰色かび病
次元 2 : うどんこ病
次元 3 : ナミハダニ
次元 4 : ハスモンヨトウ
次元 5 : オオタバコガ
次元 6 : ミカンキイロアザミウマ
次元 7 : ワタアブラムシ
次元 8 : アブラムシ
次元 9 : コナジラミ
```

---

## 2. ENTRY_VECTORの定義

### 定義
```
ENTRY_VECTOR e ∈ [0, 1]^10
```

### 意味
「現在の病害虫発生リスク予報」。各病害虫のリスク値（0〜1のスコア）を保持。

### ★ 絶対的リスク値
```
e_i ∈ [0, 1]    （各病害虫の絶対的な発生リスク度）
Σ e_i ≠ 1       （正規化しない）
```

**ENTRY_VECTORの各成分は独立した絶対的リスク値であり、合計は1になりません。**

---

## 3. リスク値生成方法

### 計算ステップ

```
ステップ1：各病害虫の「月別出現頻度」を計算
  例：灰色かび病が6月に出現した日数 = 8日

ステップ2：月内最大値で割って頻度係数（0〜1）に正規化
  例：6月の灰色かび病出現日数 = 8日（6月最多）
      6月の炭疽病出現日数 = 4日
      → 灰色かび病: 8/8 = 1.0
         炭疽病: 4/8 = 0.50

ステップ3：季節係数を乗算（病害虫の季節性を反映）
  例：ナミハダニは秋に発生が本格化 → 10月の係数を高く設定

ステップ4：最終リスク値を[0, 1]にクリップ
  e_i = min(1.0, 頻度係数 × 季節係数)
```

## 8. 絶対的リスク値の理由

EvalBoxベクトルは「構成パターン（0/1）」しか持たない。
絶対的リスク値と比較することで、以下の**3つの情報**を同時に得られる：

| 軸 | 説明 | 絶対的リスクで可能か |
|----|------|---------------------|
| ① どの病害虫が dominant か | 構成比・パターン | ○ 成分の大小関係で判断 |
| ② 全体のリスクレベル | 絶対的な強さ | **○ 成分の絶対値で判断** |
| ③ どのセットパターンに似ているか | 類似度 | ○ dot productで判断 |

### 例：2つの状況の比較

**状況A（高リスク・多発）**
```
e_A = [0.9, 0.8, 0.7, 0.0, 0.0, ...]
炭疽・灰色かび・うどんこ、すべて高リスク → 即散布が必要
```

**状況B（低リスク・軽微）**
```
e_B = [0.1, 0.05, 0.02, 0.0, 0.0, ...]
炭疽・灰色かび・うどんこ、すべて低リスク → 監視でよい
```

```
Set7 = [1,1,1,0,0,...]

e_A · v_7 = 0.9 + 0.8 + 0.7 = 2.4  ← 高い → 散布実行
e_B · v_7 = 0.1 + 0.05 + 0.02 = 0.17 ← 低い → 監視継続
```

絶対的リスクなら「同じセットが最類似でも、リスクレベルで散布可否を判断できる」。

## 9. ベクトル演算：セット選択

### 推奨：内積（ドット積）

```
score_k = e · v_k = Σ e_i × v_k_i
スコアが最も高いセット k を選択
```

- 単純で計算コストが低い
- 絶対的リスクの「強さ」をそのまま反映
- 例：e=[0.9,0.8,0.7,0,...] と Set7=[1,1,1,0,...] の dot = 2.4

### 閾値判定

```
score_k > 閾値  → 散布実行
score_k < 閾値  → 監視継続
```
