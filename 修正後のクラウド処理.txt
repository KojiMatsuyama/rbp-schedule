クラウド処理手順 — GitHub Push → Cloudflare Pages 反映
====================================================================
最終更新: 2026-08-16
対象プロジェクト: rbp-schedule (KojiMatsuyama/rbp-schedule)
デプロイ先: https://rbp-schedule.pages.dev

====================================================================
■ 前提条件
====================================================================
- リポジトリ: git@github.com:KojiMatsuyama/rbp-schedule.git
- ワーキングディレクトリ: /home/ko_matsuyama/app/STB
- Cloudflare Pages 自動デプロイ（git push origin main でトリガー）
- wrangler.toml あり（name = "rbp-schedule"）

====================================================================
■ ステップ1: 変更内容を確認
====================================================================
git diff --stat
→ どのファイルが変更されたかを確認

git diff -- data/diseases.js index.html schedule_app.css server.py
→ 主要ファイルの中身を確認（ビルド成果物 .hi/.o は含めない）

====================================================================
■ ステップ2: 本番ファイルのみステージング＆コミット
====================================================================
git add data/diseases.js index.html schedule_app.css server.py

git commit -m "feat: <変更内容を簡潔に記述>"

※ 注意:
  - dist-newstyle/ 配下の Haskell ビルド成果物はコミットしない
  - node_modules/, *.db, *.json(built), settings.local.json は除外
  - .gitignore で適切にフィルタリングされていることを確認

====================================================================
■ ステップ3: GitHub にプッシュ
====================================================================
git push origin main

→ 成功メッセージ: "main -> main" が表示されればOK

====================================================================
■ ステップ4: Cloudflare Pages への自動デプロイ待ち
====================================================================
git push 後、Cloudflare Pages が自動的に検知してデプロイを開始。

公開URL: https://rbp-schedule.pages.dev/

デプロイ状況の確認:
  curl -s -o /dev/null -w "%{http_code}" https://rbp-schedule.pages.dev/
  → 200 が返ればサイトは稼働中

ブラウザで https://rbp-schedule.pages.dev/ を開き、変更が反映されていることを確認。

====================================================================
■ エラーハンドリング
====================================================================
• git push が拒否された場合:
  - ローカルとリモートの差分がある → git pull --rebase してから再push

• Cloudflare Pages のデプロイが失敗した場合:
  - Cloudflare Dashboard (https://dash.cloudflare.com/) → Pages → rbp-schedule → Deployments
  - 失敗したデプロイの詳細ログを確認
  - wrangler.toml の compatibility_date や依存関係を見直す

• サイトが 502/520 エラーを返す場合:
  - デプロイがまだ完了していない可能性 → 1〜2分待ってから再試行

====================================================================
■ 補足情報
====================================================================
- Cloudflare = クラウドフレア（正表記）
- Dash URL: https://dash.cloudflare.com/
- Pages URL: https://rbp-schedule.pages.dev/
- wrangler 直デプロイは権限なし → git push のみ使用可能
- デプロイ完了まで通常 1〜3 分程度
